# Batch Package Export for InDesign

## Stop packaging InDesign documents one by one.

When a production contains dozens or hundreds of Adobe InDesign documents, packaging each file manually quickly becomes repetitive.

Open a document. Package it. Choose the destination. Collect fonts and links. Export additional files. Close it. Start again.

Batch Package Export automates this workflow by processing multiple InDesign documents and creating clean, organized production packages.

Generate optional PDF and IDML files, collect fonts and linked graphics, apply smart filters, run production checks, and generate a detailed processing report.

Designed for real production workflows.

## Why this tool exists

Adobe InDesign already provides a packaging workflow for individual documents.

That works well when you only need to package one or two files.

The problem changes when a production contains:

* dozens of InDesign documents
* recurring packaging workflows
* multiple deliverables per document
* linked graphics and fonts
* PDF and IDML requirements
* outdated or unwanted files that must be excluded
* production issues that need to be identified
* large projects where manually repeating the same process becomes inefficient

In these situations, packaging is no longer a single action.

It becomes a repetitive production workflow.

Batch Package Export automates that workflow.

## Built for real production workflows

Production folders are rarely perfectly clean.

They may contain:

```text
Project/
├── Final.indd
├── Final-v2.indd
├── TEST.indd
├── OLD.indd
├── Archive.indd
├── Draft.indd
└── Backup.indd
```

Processing every file automatically may create unnecessary packages.

Batch Package Export includes smart filtering to help exclude files that should not be part of the production batch.

For example:

```text
TEST
DRAFT
OLD
ARCHIVE
BACKUP
```

You can also process files based on modification dates.

## More than packaging

A packaging workflow is often one of the final steps before:

* delivery
* printing
* archiving
* transferring a project
* sending files to another production team

For this reason, Batch Package Export also includes production-oriented checks.

The workflow can help identify:

* missing links
* missing fonts
* overset text

Detected issues are included in the production process and reporting workflow.

---

## Fail-safe batch processing

Large batches do not always contain perfect documents.

A specific file may encounter a problem during processing.

Instead of requiring the entire batch to stop, Batch Package Export is designed to continue processing the remaining documents while recording the results.

This helps prevent one problematic file from blocking the entire production workflow.

## When does batch packaging make sense?

| Project               | Recommended approach                             |
| --------------------- | ------------------------------------------------ |
| 1 document            | Native InDesign packaging                        |
| A few documents       | Manual packaging may be sufficient               |
| 10–20 documents       | Evaluate the amount of repetition                |
| Dozens of documents   | Batch packaging can save significant time        |
| Hundreds of documents | Automated processing becomes increasingly useful |
| Recurring projects    | Standardized batch workflow                      |

Batch Package Export is designed for the point where packaging documents manually becomes repetitive production work.
